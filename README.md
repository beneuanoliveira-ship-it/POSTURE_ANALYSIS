# POSTURE ANALYSIS

Avaliação postural digital baseada em fotogrametria.

Este repositório contém uma versão web experimental do sistema, estruturada em torno do Protocolo de Portland. A classificação 5/3/1 deve ser calibrada e validada contra avaliadores humanos antes de qualquer uso científico ou clínico automatizado.

## Publicação
O workflow em `.github/workflows/deploy.yml` publica o site no GitHub Pages a cada push na branch `main`.

## Escopo
Protótipo experimental. Não é ferramenta diagnóstica nem substitui avaliação profissional.
